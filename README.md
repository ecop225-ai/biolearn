# BioLearn

Plataforma educativa de biología con 5 roles (Administrador, Docente, Contador, Representante institucional, Estudiante), gestión de cursos, evaluaciones, foros, certificados, y pagos.

Este repositorio contiene el sistema completo:

```
biolearn/
 ├── backend/     → API REST en Java + Spring Boot + MySQL
 └── frontend/    → Interfaz web en React
```

- Arquitectura del sistema (capas, diagrama de paquetes, clases, componentes)
- Diagrama Entidad-Relación y diccionario de datos (51 tablas)
- Historias de usuario y requerimientos del sistema
- Mecanismos de seguridad
- Mapa de navegación
